## [Unreleased]

## [0.1.1] - 2026-09-15

### Changed

- Clarified Pi package installation, runtime, configuration, and extension behavior.
- Refreshed package and repository metadata.

## [0.1.0] - 2026-08-05

### Added

- Pi extension port of OpenCode Goal.
- Persistent `/goal` lifecycle with status, pause, resume, and clear controls.
- Independent completion evaluation after settled agent turns.
- Automatic continuation, optional token and turn budgets, and interruption safeguards.
- `create_goal`, `get_goal`, and `update_goal` model tools.
- Session-branch-aware state persistence, footer status, and editor widget.
